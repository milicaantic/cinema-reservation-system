O aplikaciji

Aplikacija predstavlja informacioni sistem namenjen upravljanju poslovanjem bioskopa.

Funkcionalnosti

  • Pregled bioskopa
  • Pregled sala
  • Pregled filmova
  • Pregled rezervacija
  • Dodavanje novih podataka
  • Izmena postojećih podataka
  • Brisanje podataka

Tehnologije

Komponenta Tehnologija
Frontend Angular
Backend Spring Boot
Baza podataka PostgreSQL
ORM JPA / Hibernate
